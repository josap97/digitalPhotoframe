# digitalPhotoframe
 A digital version of a photoframe powered by Python
Two versions of the frame exist, a standard one in `frame.py` and one that allows overlays to be added to your photos in `polaroid.py` as that was my first inspiration.

# Usage
1. To add your own photos to the frame, create a new folder in the `images` folder. Give it a recognisable but short name.
2. Open a terminal in the root folder.
3. Run the version you are interested in with `python frame.py` or `python polaroid.py`.
4. Choose the correct folder by typing the number associated with the folder name of interest and pressing `<enter>`
To stop the frame, `<alt>+<tab>` to the terminal window and press `<ctr>+<c>`
